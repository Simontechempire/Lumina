 🌟 Lumina

**WhatsApp Bot controlled by Telegram**  
Owned by **Simon Tech**

---

## Features

- Control everything from Telegram
- `/pair` or `/connect` → Generate QR & link WhatsApp
- `/status` → Check connection & uptime
- `/restart` → Restart the bot
- `/repair` → Clear session & re-pair
- Works on **Render** free tier
- Automatic keep-alive
